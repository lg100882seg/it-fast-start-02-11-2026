Main git commands

  • git status - команда яка відображає поточний стан змін та файлів
  • git branch - перелік усіх локальних гілок
  • git checkout - перемикання на іншу гілку
  • get add. - додавання файлів до зони підготовки (staging area) перед комітом
  • get commit -m - створення коміту (фіксація змін) із текстовим описом
  • get push origin HEAD - відправляє ваші локальні коміти (зафіксовані зміни) на віддалений репозиторій на GitHub
  • git clone - створює повну локальну копію існуючого віддаленого репозиторію (з GitHub) на вашому комп'ютері
  • git log - перегляд історії комітів
